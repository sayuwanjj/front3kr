О приложении

Архитектура App Shell

TaskFlow Offline использует лёгкую оболочку приложения, которая кэшируется при первом посещении, а навигационные страницы подгружаются по стратегии Network First.

Проверяем соединение... Проверяем HTTPS... Socket.IO: подключение...

Что входит в App Shell

Общая оболочка состоит из навигации, базовой типографики, стилей, JavaScript-логики, манифеста и иконок. Эти ресурсы заранее попадают в кэш и позволяют быстро открыть интерфейс даже без сети.

Как работает офлайн-режим

Список заметок хранится в localStorage, поэтому просмотр и добавление записей не зависят от соединения. При отсутствии сети страницы открываются из кэша, а приложение остаётся работоспособным.

Стратегия загрузки страниц

Для навигации между страницами используется стратегия Network First: браузер сначала пытается получить свежую версию страницы из сети, а при ошибке или офлайн-режиме возвращает последнюю кэшированную копию.

HTTPS и установка

Для полноценной работы Service Worker и установки PWA приложение нужно открывать по HTTPS или через `localhost` в процессе локальной разработки.
