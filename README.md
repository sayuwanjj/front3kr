# TaskFlow Offline

Веб-приложение для заметок и задач, приведённое в соответствие с практиками №13-17 по дисциплине «Фронтенд и бэкенд разработка».

## Что покрыто

- `№13 Service Worker`: регистрация `Service Worker`, кэширование статических ресурсов, офлайн-доступ;
- `№14 Web App Manifest`: `manifest.json`, иконки, мета-теги, установка PWA;
- `№15 HTTPS + App Shell`: App Shell, отдельные страницы, офлайн-кэш, поддержка запуска по локальному HTTPS при наличии сертификатов `localhost.pem` и `localhost-key.pem`;
- `№16 WebSocket + Push`: сервер на `Express`, `Socket.IO`, VAPID-ключи, подписка и отписка от push, события `newTask` и `taskAdded`;
- `№17 Детализация Push`: форма заметки с напоминанием, хранение `reminder` в `localStorage`, серверное планирование через `setTimeout`, кнопка `Отложить на 5 минут` в уведомлении и обработка `/snooze`.

## Основные файлы

- `index.html` — главная страница со списком задач и формой напоминания;
- `contacts.html` — доступная страница контактов;
- `about.html` — страница `О нас`;
- `app.js` — логика задач, напоминаний, `Socket.IO`, push и A11y-формы;
- `server.js` — HTTP/HTTPS сервер, `Socket.IO`, push и планирование напоминаний;
- `sw.js` — кэширование, push и action-кнопка snooze;
- `manifest.json` — PWA-манифест;
- `styles.css` — стили интерфейса.

## Установка и запуск

```bash
npm install
npm start
```

После этого приложение доступно по адресу:

- `http://localhost:3000`

Если в корне проекта лежат файлы `localhost.pem` и `localhost-key.pem`, сервер дополнительно поднимет:

- `https://localhost:3443`

## Как проверить практики

### Практика 13

1. Откройте приложение онлайн.
2. Проверьте в DevTools, что `sw.js` зарегистрирован.
3. Отключите сеть и убедитесь, что страницы открываются из кэша.

### Практика 14

1. Убедитесь, что браузер видит `manifest.json`.
2. Проверьте наличие иконок и возможность установки PWA.

### Практика 15

1. При наличии `localhost.pem` и `localhost-key.pem` откройте `https://localhost:3443`.
2. Проверьте, что `Service Worker` и App Shell работают в secure context.

### Практика 16

1. Откройте приложение в двух вкладках.
2. Добавьте обычную заметку.
3. Убедитесь, что сервер получает `newTask`, а клиент показывает toast по событию `taskAdded`.
4. Включите push-уведомления и проверьте `/subscribe` и `/unsubscribe`.

### Практика 17

1. Создайте заметку через форму `Заметка с напоминанием`.
2. Убедитесь, что в `localStorage` запись содержит `id` и `reminder`.
3. Дождитесь push-уведомления.
4. Нажмите в уведомлении `Отложить на 5 минут`.
5. Убедитесь, что сервер обработал `/snooze` и уведомление приходит повторно через 5 минут.
